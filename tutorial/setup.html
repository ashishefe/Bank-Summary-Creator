Setting Up Claude Code on Windows

Everything you need, step by step. About 15 minutes total.

We need to install a few things on your Windows machine before Claude Code can run. Don't worry — each step is straightforward, and I'll tell you exactly what to expect.

Install Node.js

Node.js is a program that lets your computer run JavaScript — the language Claude Code is built with. You don't need to learn JavaScript; this is just plumbing that runs in the background.

Go to nodejs.org and download the LTS version (the big green button). Run the installer — click Next, Next, Next, Finish. Accept all the defaults.

What you should see after: The installer finishes without errors. That's it — no need to open anything yet.

Open Terminal (PowerShell)

The Terminal is the text-based interface where you'll talk to Claude Code. Think of it like a command window — you type instructions, and the computer responds.

Press the Windows key on your keyboard, type Terminal, and click Windows Terminal (or "PowerShell" — either works). A dark window with a blinking cursor will open.

What you should see: A window with text like PS C:\Users\YourName> and a blinking cursor. This is where you'll type all the commands below.

Verify Node.js Installed Correctly

Let's make sure Node.js installed properly. In your terminal, type:

node --version
What you should see: Something like v22.x.x (the exact number doesn't matter, as long as it shows a version). If you see an error like "not recognized," close the terminal, reopen it, and try again — sometimes Windows needs a fresh terminal to pick up new programs.

Install Claude Code

Now we install Claude Code itself. Type this command in your terminal:

npm install -g @anthropic-ai/claude-code

npm is the package manager that came with Node.js — it downloads and installs programs. This command installs Claude Code globally on your machine so you can use it from any folder.

What you should see: A bunch of text scrolling by as it downloads. It may take a minute or two. When it's done, you'll see your cursor again with no error messages in red. If you see warnings (yellow text), those are fine — warnings are not errors.

Set Up Claude Max Subscription

Claude Code requires a Claude Max subscription from Anthropic. This is a monthly plan that gives you unlimited usage — perfect for a project like this.

Go to claude.ai, create an account (if you don't have one), and subscribe to the Max plan. You'll need this before Claude Code can authenticate.

What you should see: A confirmed subscription on your Claude account page. Keep your login credentials handy — you'll need them in a moment.

Create Your Workspace

Let's create a folder where all your projects will live. In your terminal:

mkdir Projects cd Projects

mkdir creates a new folder. cd moves you into it. Simple as that.

What you should see: Your terminal prompt changes to show PS C:\Users\YourName\Projects>. You're now inside your new Projects folder.

Run Claude Code for the First Time

The moment of truth. Type:

claude

The first time you run this, Claude Code will ask you to log in. It will open your web browser to authenticate with your Anthropic account. Log in, approve the connection, and come back to your terminal.

What you should see: After authentication, Claude Code starts up in your terminal. You'll see a welcome message and a prompt where you can start typing. If you see this — congratulations, you're set up!
Something went wrong?

If any step doesn't work as described, don't struggle alone. Take a screenshot of the error message and send it to Ashish on WhatsApp. Most setup issues are small things — a typo, a permission setting, a restart needed — and are quick to fix.

Pro tip

You can always type claude in any terminal window to start a conversation with Claude Code. It's like opening a chat — except this chat can read files, write code, and run commands on your computer.
